# 掌中星河 · Heart Nebula

一个用手掌控制的互动粒子动画。张掌时，粒子旋转扩散成星尘。握拳时，星尘重新聚成发光爱心或螺旋星河。两种形态之间可以平滑变形，适合全屏展示和录制短视频。

## 快速开始

1. 下载仓库里的 `index.html`，用 Chrome 或 Edge 双击打开。
2. 页面会自动演示爱心、星河和粒子聚散。也可以点击底部按钮，手动选择形态。
3. 想用手控制时，点击 **开启手势**，允许浏览器访问摄像头，等模型加载完毕后，把一只手完整放进画面。

动画和鼠标操作可离线使用。手势模式需要联网获取 MediaPipe 运行库和模型，摄像头画面在浏览器内处理。

## 操作

| 操作 | 效果 |
| --- | --- |
| 张开手掌 | 粒子扩散成旋转的星尘 |
| 握拳 | 粒子聚合成当前形态 |
| 先分开拇指和食指，再轻捏一下 | 切换爱心和星河。其余手指尽量伸开，轻捏后松开即可再次切换 |
| 按住画面，再松开 | 用鼠标或触屏控制散开和聚合 |
| 拖动「聚散」滑块 | 手动设定扩散程度 |
| 空格 | 切换爱心和星河 |
| H 或点击「纯画面」 | 隐藏控件和摄像头预览。再按 H 或按 Esc 恢复 |
| 自动演示 | 自动循环两种形态和聚散效果 |

手势跟踪期间，手势优先控制聚散。想改用鼠标或滑块时，可以点击 **关闭手势**。

## 录制短视频

点 **纯画面** 隐藏界面，按 F11 进入浏览器全屏，再使用系统录屏工具。可以先握拳让形态聚拢，再张掌散开，最后捏一下切换形态并握拳收尾。

## 源码

`index.html` 包含完整的页面、样式、JavaScript 和 GLSL 着色器，无需安装依赖或执行构建。WebGL 模式绘制 42,000 颗主体粒子。WebGL 无法初始化时，页面自动切换到 21,000 颗主体粒子的 Canvas 2D 模式。

手势模式使用 [Google MediaPipe Hand Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/web_js)。版本固定为 `@mediapipe/tasks-vision@0.10.21`，运行库从 jsDelivr 加载，模型从 Google 的模型资源地址加载。

## 常见问题

- **手势没反应**。确认摄像头权限已开启，模型加载成功，手腕和指尖都在镜头里。光线不足时，可以试着增加照明。
- **模型加载失败**。检查网络是否能访问 `cdn.jsdelivr.net` 和 `storage.googleapis.com`，再点一次「开启手势」。这时仍可以用鼠标和自动演示。
- **按空格没有切换**。焦点在按钮或滑块上时，空格会操作当前控件。也可以直接点击「爱心」或「星河」。
